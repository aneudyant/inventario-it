# Inventario del Departamento de IT

Aplicación web CRUD para gestionar equipos, periféricos y recursos del departamento de IT (**insertar**, **consultar**, **modificar** y **borrar** registros) utilizando **Node.js**, **Express**, **SQLite** y **HTML/CSS/JavaScript**.


Este proyecto fue desarrollado con apoyo de herramientas de Inteligencia Artificial (geminis) como asistente de programación para estructurar el proyecto.
